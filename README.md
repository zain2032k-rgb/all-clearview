# ClearView Client (Fabric, Minecraft 1.21.11)

- Creamy Keys: the recorded keyboard sounds (Aula F75, FB67, 60he v2, Frosted 65) + mouse click. Sounds from SoberClient by Violet (GPL-3.0), see NOTICE.md
- Swing animations + slow swing speed, small held items
- Blossom loading screens (connecting, joining, saving, loading terrain) and a blossom Multiplayer loading screen
- Panel settings GUI: RIGHT SHIFT in game, or the ClearView button on the main menu
- FPS boost (F8), FPS counter (F9), custom main menu, 12 totem packs
- Free look (hold Left Alt by default, rebind it in the View tab) and a Clear weather option that hides rain, snow and storms on your screen only
